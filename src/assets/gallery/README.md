# Gallery Photos

Drop your work photos here. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

The gallery page will automatically pick up any image you add to this folder — no code changes needed.

## Tips
- Name files descriptively, e.g. `fade-cut-jan.jpg`, `box-braids-mary.jpg`
- Recommended size: at least 800×1000px for best quality
- Portrait orientation (taller than wide) looks best in the grid
